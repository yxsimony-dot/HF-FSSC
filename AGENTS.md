# Repository Instructions

- After every source, UI, configuration, or behavior change, synchronize the latest working application build to `publish/FSSCWebLauncher`.
- Verify the change by launching `publish/FSSCWebLauncher/FSSCWebLauncher.exe`.
- Do not consider a change complete until the published version has been updated and verified.
- If a full self-contained publish is unavailable, update the application binaries in the existing self-contained publish directory and verify that version.
